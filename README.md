# LocationAutoDZ

Offline vehicle-rental contracts & returns tracker for Algerian agencies.
Kotlin + Jetpack Compose (Material 3) + MVVM + Room. FR/AR. 100% offline.

## Features
- Vehicles, clients, rental contracts, returns (km, fuel %, damages, extra charges in DZD)
- Bilingual FR/AR contract PDF (offline, `android.graphics.pdf`)
- No INTERNET permission — all data stays on device (Room)
